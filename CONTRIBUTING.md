# Contributing

Build and run the tests described in README.md before submitting a change. Keep discovery format-based; do not add guessed hotkeys for named mods. Keep config edits conservative and preserve backups, unrelated text, and controller bindings.

For bug reports include the ModActivator version, game version, overlay/mod combination, relevant anonymized config sections, and reproduction steps. Review logs for personal paths before posting. Report whether an issue occurs with frame generation enabled. Live toggle state must not be inferred from a sent shortcut.
